## AI学习路线图 — 按周详细计划

这是一份约6个月(24周)的学习计划,假设每周投入10-15小时。可以根据自己的节奏灵活调整。

### 第一阶段:基础准备(第1-4周)

**第1周:Python基础**

- 语法、数据结构(列表、字典、集合)、函数、类
- 目标:能独立写出简单的脚本处理数据

**第2周:数据处理工具**

- NumPy(数组运算、广播机制)
- Pandas(读取数据、清洗、筛选、分组统计)
- 目标:能加载一个CSV数据集并做基本分析

**第3周:数学基础 I — 线性代数**

- 向量、矩阵运算、矩阵乘法
- 特征值与特征向量(直觉理解即可,不必深究证明)
- 结合NumPy动手实现矩阵运算

**第4周:数学基础 II — 微积分与概率**

- 导数、梯度、链式法则
- 概率分布、期望、方差、贝叶斯定理
- 目标:理解"梯度下降是怎么回事"

### 第二阶段:经典机器学习(第5-9周)

**第5周:机器学习总览**

- 监督/无监督/强化学习的区别
- 回归 vs. 分类
- 用scikit-learn跑通第一个模型(如线性回归)

**第6周:回归与分类算法**

- 线性回归、逻辑回归
- 决策树、随机森林
- 动手项目:用经典数据集(如房价预测)训练模型

**第7周:模型评估**

- 训练/验证/测试集划分、交叉验证
- 评估指标:准确率、精确率/召回率、F1、ROC-AUC、RMSE
- 过拟合与欠拟合、偏差-方差权衡

**第8周:更多算法与特征工程**

- SVM、k-NN、k-means聚类
- 特征工程、数据标准化/归一化
- 正则化(L1/L2)

**第9周:综合项目**

- 完整走一遍机器学习流程:数据清洗 → 特征工程 → 训练 → 调参 → 评估
- 建议选一个Kaggle入门数据集练手

### 第三阶段:深度学习(第10-15周)

**第10周:神经网络基础**

- 神经元、层、激活函数(ReLU、Sigmoid、Softmax)
- 前向传播
- 选定框架:PyTorch(推荐)

**第11周:反向传播与训练**

- 反向传播原理
- 损失函数、优化器(SGD、Adam)
- 用PyTorch手写一个简单的全连接网络

**第12周:训练技巧**

- 批归一化、Dropout、权重初始化
- 学习率调整、早停法(Early Stopping)
- 调试常见训练问题(梯度消失/爆炸)

**第13周:CNN(卷积神经网络)**

- 卷积、池化操作原理
- 经典架构了解(如ResNet)
- 项目:图像分类(如MNIST或CIFAR-10)

**第14周:序列模型与Transformer入门**

- RNN/LSTM基本原理(了解即可)
- 注意力机制、自注意力
- Transformer架构详解

**第15周:深度学习综合项目**

- 完整训练一个深度学习模型并调优
- 建议:图像分类或简单文本分类任务

### 第四阶段:大语言模型专题(第16-20周)

**第16周:NLP基础**

- 分词(Tokenization)、词嵌入(Word Embeddings)
- 语言模型的基本概念

**第17周:预训练与微调**

- 预训练 vs. 微调的区别
- 迁移学习思路
- 动手用Hugging Face微调一个小模型

**第18周:提示词工程与RAG**

- Prompt Engineering技巧
- 向量数据库、Embedding检索
- RAG(检索增强生成)原理与简单实现

**第19周:高阶微调技术**

- LoRA、PEFT等参数高效微调方法
- RLHF(基于人类反馈的强化学习)概念

**第20周:AI智能体(Agents)**

- 工具调用(Tool Use)原理
- 智能体架构、多步推理
- 动手用API搭建一个简单的Agent

### 第五阶段:实战与部署(第21-24周)

**第21周:生成式模型**

- GAN、VAE、扩散模型基础原理
- 选做:体验一个开源扩散模型

**第22周:MLOps与部署**

- 模型版本管理、部署流程
- 模型监控与迭代

**第23周:AI伦理与安全**

- 偏见与公平性问题
- 可解释性、模型安全性

**第24周:毕业项目**

- 挑选一个感兴趣的方向,独立完成一个端到端项目
- 建议整理成作品集,方便求职或展示

### 使用建议

- 每周结束时做一个小项目巩固,而不是只看理论
- 第1-9周(基础+经典ML)是地基,不要跳过
- 如果目标是快速进入大语言模型领域,可以在第9周后适当压缩深度学习部分,提前进入第16-20周内容
- 遇到数学难点时不要死磕,先建立直觉,后续实践中会自然加深理解
