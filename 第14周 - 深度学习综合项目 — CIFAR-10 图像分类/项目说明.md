## 第14周:深度学习综合项目 — CIFAR-10 图像分类

这周把第10-13周的内容串成一个完整项目:**数据增强 → ResNet风格网络 → 学习率调度 → 早停保存最佳模型 → 误差分析**。CIFAR-10 是 10 类彩色小图(飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车),比 MNIST 难得多。


### 这个项目里每个设计的作用

- **数据增强** — 训练时随机裁剪、翻转、颜色扰动,相当于让模型每轮看到"稍微不同"的图,等于免费扩充数据集,是图像任务里最有效的防过拟合手段。验证集和测试集**不做增强**,因为我们要评估的是模型在真实原图上的表现。
- **残差块** — 第12周提过的 ResNet 核心思想,`out + shortcut(x)` 让梯度有一条"高速公路"直通前面的层。
- **全局平均池化** — 比"展平+大全连接层"参数少得多,也更不容易过拟合。
- **`OneCycleLR`** — 学习率先升后降,通常收敛更快、最终效果更好。注意它要**每个 batch** 调一次 `scheduler.step()`,而不是每个 epoch。
- **`weight_decay`** — AdamW 里的权重衰减,就是第8周学的 L2 正则化。
- **保存最佳模型 + 早停** — 以验证集准确率为准,而不是训练到最后一轮。
- **三份数据分工** — 训练集学习参数、验证集选模型/早停、测试集只在最后评估一次,和第7周讲的一致。

### 预期结果与排查

- 15个epoch后,测试集准确率大约在 **85%~90%** 之间,有GPU的话每个epoch几十秒,纯CPU会慢不少(可以先把 `epochs` 改成 5 跑通流程)。
- 混淆矩阵里你大概率会看到 **猫↔狗**、**鸟↔飞机**、**卡车↔汽车** 这些相似类别最容易混。这就是"误差分析"的价值:知道模型错在哪,才知道下一步该改数据还是改模型。
- 如果训练准确率远高于验证准确率,说明过拟合,可以加大数据增强强度或 `weight_decay`。如果两者都很低,说明欠拟合,可以加宽网络或多训练几轮。



### 拓展:迁移学习(下面几周会反复用到的思路)

不从零训练,而是拿别人在 ImageNet 上预训练好的模型,只替换最后一层、在自己的数据上微调:

python

```python
from torchvision import models

model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)   # 加载预训练权重

for param in model.parameters():
    param.requires_grad = False                    # 冻结所有预训练层

model.fc = nn.Linear(model.fc.in_features, 10)     # 只替换最后一层(新层默认可训练)

optimizer = optim.Adam(model.fc.parameters(), lr=1e-3)   # 只优化这一层
```

预训练模型要求输入更大的图(通常 224×224),所以实际用在 CIFAR-10 上需要在 transform 里加 `transforms.Resize(224)`,CPU 上会比较慢,可以以后有 GPU 时再试。**重点是理解这个思路:** 预训练模型已经学会了"怎么看图"(边缘、纹理、形状),我们只需要教它"你的任务有哪几类"。大语言模型的微调用的是同一个思想,下一阶段你会看到。
